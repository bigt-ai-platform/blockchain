# Test wallets

One wallet JSON per test key from [`../TestKeys`](../TestKeys), in the Bigtangle
app's wallet format. Generated by `bapp/scripts/generate-test-wallets.mjs`
(bigtangle-ts `PQKey.fromPrivateKeyHex`).

| file | role | seed (byte ×32) | address |
|---|---|---|---|
| `genesis-wallet.json` | genesis wallet | `01` | `mnvGDASDFGpHXycAadQC4STYFNwfhfTGsf` |
| `yuan-wallet.json` | yuan token issuer | `03` | `mizQPijhrrdR98aKR7D18pRbRMretYPjaj` |
| `l0-validator.json` | Layer-0 validator | `04` | `n2cKSV6WuE3cd4XD2jcvi15BVwjm6XGd7n` |
| `l1-validator.json` | L1-order validator | `05` | `mikXSgivoeHey8PRQMPL8YmLZ1HBiJYUzZ` |

Note: the current `remote.sh` bootstrap runs the L1-order chain with the L0
validator key (seed `04`) so the imported L0 deposit can start the L1 beacon
chain — use `l0-validator.json` for that.

## Two formats per role

- **`<role>.json`** — plain `SerializedWallet` (scripts / tests / harness):
  ```json
  {
    "wallet": {
      "address": "<base58, TestParams (m…/n…) encoding>",
      "pubkey": "<prefixed PQ pubkey hex (050101…) >",
      "privateKey": "<serialized PQ private key hex — PQKey.fromPrivateKey()>",
      "seed": "<32-byte ML-DSA seed hex — PQKey.fromPrivateKeyHex()>",
      "keyType": "PQ",
      "network": "Test"
    },
    "credentials": { "url": "...", "user": "...", "password": "<random>" }
  }
  ```
- **`<role>.enc.json`** — the app's **encrypted** wallet-file format
  (`saveKeyToFile` output: `salt/iv/data/N/r/p`, scrypt + AES-CBC). This is what
  the **Manage Keys → Load from file** flow on `/wallet/keys` reads.

## Loading in the app (`/wallet/keys`)

The app's Load-from-file flow now accepts **both** formats (WalletHelper.ts
`loadWallet`): the encrypted `.enc.json` (decrypts with the password) and the
plain `.json` (already unencrypted; password is ignored).

1. Open `http://localhost:8081/wallet/keys` → **Load from file**.
2. Pick e.g. `l0-validator.enc.json` (or `l0-validator.json`).
3. For an `.enc.json` file, enter the wallet password: **`bigtangle`**
   (default; override via `node scripts/generate-test-wallets.mjs <password>`).
4. The wallet (seed `04` / L0 validator) is imported and stored.

## Other import paths

- **Import private key** (Manage Keys → import): paste `privateKey` from the
  plain `<role>.json` (the serialized form `PQKey.fromPrivateKey` accepts).
- Harness / Java / tests: reconstruct from `seed` via
  `PQKey.fromPrivateKeyHex(seed)` / `PQKey.fromMLDSA(seed)`.
