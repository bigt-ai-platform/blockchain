# bigtangle-core

This module contains the core functionalities of Bigtangle.

## Building with Maven

To build the `bigtangle-core` module using Maven, navigate to the root directory of the project (where the main `pom.xml` is located) and execute the following command:

```bash
mvn clean install -DskipTests=true
```

This command will:
- `clean`: Remove the target directory generated by a previous build.
- `install`: Compile the source code, run tests (skipped with `-DskipTests=true`), and package the compiled code into a JAR file, then install it into the local Maven repository.
- `-DskipTests=true`: Skips the test execution. Remove this flag if you wish to run the tests during the build.

Alternatively, to build only this module without installing it to the local Maven repository, you can navigate into the `bigtangle-core` directory and run:

```bash
cd bigtangle-core
mvn clean package -DskipTests=true
```

This will compile and package the module into a JAR file in the `bigtangle-core/target/` directory.
